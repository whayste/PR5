## 1. Название и что делает

**Kostroma Coffee Love** — это десктопное приложение для управления сетью кофеен. Оно предназначено для администраторов и бариста, позволяя им централизованно управлять меню напитков, базой данных сотрудников и информацией о филиалах сети. 

Приложение реализует:
- Строгую ролевую модель (разграничение прав доступа: `admin` и `barista`).
- Комплексную валидацию вводимых данных (проверка формата email, сложности пароля, уникальности полей).
- Автоматическое логирование действий пользователей в защищённую директорию `logs`.
- Функцию экспорта табличных данных в формат CSV.

## 2. Стек технологий

- **Язык программирования:** Python 3.8+
- **Графический интерфейс (GUI):** Tkinter (стандартная библиотека Python)
- **База данных:** SQLite 3 (локальное файловое хранилище, стандартная библиотека)
- **Вспомогательные модули:** исключительно стандартные библиотеки Python (`hashlib` для хеширования паролей, `csv` для экспорта, `re` для валидации по регулярным выражениям, `datetime` и `os` для системы логирования).

## 3. Как установить

1. Убедитесь, что на компьютере установлена среда выполнения **Python версии 3.8 или выше**. Скачать официальный дистрибутив можно на сайте [python.org](https://www.python.org/).
2. ⚠️ **Важно:** в процессе установки Python обязательно поставьте галочку напротив пункта **"Add Python to PATH"** (Добавить Python в переменные среды).
3. Скачайте или клонируйте архив с исходным кодом проекта из удалённого репозитория на свой компьютер.
4. Распакуйте архив в любую удобную директорию (например, `C:\Projects\kostroma_coffee`).
5. Установка дополнительных сторонних библиотек через менеджер пакетов (`pip install`) **не требуется**, так как проект использует исключительно встроенные средства языка Python.

## 4. Как запустить

1. Откройте командную строку (в Windows: нажмите `Win + R`, введите `cmd` и нажмите Enter) или терминал (в macOS/Linux).
2. Перейдите в папку с проектом с помощью команды `cd`. Например:
   ```bash
   cd C:\Projects\kostroma_coffee
   ```
3. Запустите главный исполняемый файл приложения следующей командой:
   ```bash
   python main.py
   ```
4. При первом запуске приложение автоматически создаст файл базы данных `kostroma_coffee.db` и директорию `logs` для записи журналов событий.

5. *(Опционально)* Вы также можете создать нового пользователя (роль "barista"), нажав кнопку «Регистрация сотрудника» на стартовом экране и заполнив форму в соответствии с требованиями к валидации полей.
